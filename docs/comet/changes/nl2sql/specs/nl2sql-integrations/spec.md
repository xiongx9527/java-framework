# nl2sql-integrations 完整目标规格（实现 change）

> **文档角色**：本文档承接 `docs/comet/changes/nl2sql/brief.md` 中「验收示例 → 集成（nl2sql-integrations）」小节，并结合 D11/D17/D18/D20/D21/D26/D38/D39/D40/D41 决策，定义对外集成能力的完整目标规格。本文为 Shape 产物，纯 markdown、非代码实现；实现 change 以本文各章节为验收设计基础。对外 API 的 REST/SSE 契约、MCP Server 接入、API-Key、Excel 导入、API 对接与 UI 对接、企微/钉钉/飞书嵌入集成的行为均以本文文字描述为准，不重复 brief Scenario 行全文。

fw-plus 问数（NL2SQL / ChatBI）能力除管理端插件与用户端 UI 两条 UI 通道外，还须提供面向业务系统与 MCP 客户端的开放集成面：对外 HTTP/SSE API 服务（D18）、MCP Server 接口（D40，暴露全部对外能力）、业务可对接的 API 契约（D20/D21）、两种业务对接形态的支持（D20）、内嵌第三方 IM 平台的集成跳板（D11）、Excel 数据源导入（D17/D39）以及结果与元数据的导出能力（D13 范围之外的 D43 补全）。本 change 依赖 `nl2sql-core` 提供的问数核心（编排/执行/记录库）与共享配置存储，不重复实现核心能力。

## 1. 范围与依赖

- 依赖：`nl2sql-core`（问数编排、只读执行、记录库、共享配置存储、API 服务骨架 starter）。
- 本 change 交付：对外 API 的 REST/SSE 双栈契约、MCP Server 全部对外能力暴露、API-Key 管理与鉴权、Excel 数据导入、API 对接契约文档与 UI 嵌入对照、嵌入集成的入口规范。
- 不在本 change：管理端插件（`nl2sql-admin`）、数据权限策略（`nl2sql-security` 提供 SQL 回调 SPI）、用户端 UI 本体（`nl2sql-user-ui`，本 change 仅规范其被嵌入方式）。

## 2. 对外 API 基线（REST/SSE；Servlet/WebFlux 双栈）

### 2.1 交付形态

- 按 D26 交付：核心为 starter（业务应用引入即得问数 API 服务）+ 可选独立 server 装配（演示/独立部署）+ 可选 magic 插件叠加管理端。
- 按 D18：问数 API 服务定位为 Sa-Token 授权服务端——登录认证、token 签发与接口鉴权闭环在本服务端完成；认证授权方式可按 Sa-Token 标准配置，框架不另造认证机制；用户态与权限上下文从登录态获取。业务系统可将框架提供的用户端 UI 或自有客户端作为 Sa-Token 客户端对接。

### 2.2 双栈 Web 层

- REST/SSE 对外能力同时提供 Servlet（Spring MVC）与 WebFlux（Reactive）两种栈实现：同一对外能力、同一接口契约、同一响应 JSON 结构与 SSE 事件格式；业务按部署环境二选一或同时启用。
- SSE 事件：问数对话 SSE 流式返回过程节点（表匹配/SQL 生成/执行/解读）与最终数据/图表配置/解读；客户端按事件类型消费。事件格式、字段命名、错误事件表示在契约文档中冻结。

### 2.3 对外 API 基线能力

- 问数对话与记录：发起问数（流式/非流式）、会话列表/重命名/删除/历史消息、单条记录详情（SQL、图表配置、结果快照引用、总行数）、SQL 人工调整后重执行（D44：调整后仍走只读校验与数据权限回调，保存为新记录）。
- 问数结果数据分页列表（D45）：API 接受 page/size，后端服务分页，返回当前页数据与总行数；分页在记录库中受行数限制（默认 ≤1000 行）的结果集快照上进行。
- 图表与看板入口：问数结果携带 LLM 自动产出的图表配置（类型/轴：柱/条/线/饼/表）；服务端出图 PNG（D42，对齐 SQLBot g2-ssr 能力，Java 侧渲染，不引入 Node 出图服务）；将多次问数结果保存为看板配置。
- 数据源查询/执行、表关系、推荐问题、术语、数据训练——业务消费类能力的查询接口（管理写操作经管理端 magic 插件，不要求对外 API 重复提供）。
- 结果导出：Excel/CSV + 图表图片 PNG（D43）；术语/训练示例模板导入导出；数据源 schema 导入导出。

## 3. MCP Server 接入（D40）

### 3.1 形态与复用

- 问数 API 服务除 REST/SSE 通道外，必须对外提供 MCP Server 接口，供 MCP 客户端 / AI Agent 以 tools/resources 形式调用对外 API 的全部能力。
- 复用框架 `fw-plus-ai-mcp-server` 与既有 SaTokenOAuth2 认证体系；MCP 通道与 REST/SSE 通道共享同一问数核心、同一共享配置、同一记录库。管理端能力不通过 MCP 暴露。

### 3.2 暴露的全部对外能力

- 问数对话（tools）：发起问数（可流式/非流式按 MCP 能力降级），返回与对话通道一致的问数结果与解读；可按会话维度延续上下文。
- 会话历史（resources / tools）：会话列表、按会话查询消息历史、单条记录详情（含图表配置与分页数据快照引用）。
- 图表数据（tools / resources）：返回问数结果的图表配置与分页数据列表；服务端出图能力提供 PNG 资源形态。

### 3.3 一致性

- MCP 客户端调用任一能力，返回结果与 REST/SSE 通道一致（同一配置、同一数据、同一权限校验语义）；MCP 调用的问数记录同样落记录库，可在用户端 UI 与 REST 通道查询。

## 4. 对外 API 对齐 SQLBot 业务消费类接口（D41）

- 以 SQLBot `/api/v1` 接口清单为基线，业务消费类能力在本框架对外 API 中全部提供：问数对话与记录、数据源查询/执行、表关系、推荐问题、看板、MCP、API-Key、术语、数据训练。
- 平台账号类接口（用户/工作区/助手/模型/系统参数）不提供：认证沿用框架 Sa-Token 授权服务端；角色、用户体系完全由业务决定。
- 接口交付两种形态：REST/SSE 通道 + MCP 通道；接口契约公开，业务方按契约自行组织客户端（D21）。

## 5. API-Key

- 提供 API-Key 的创建/启停/删除/查询接口（对齐 SQLBot `/system/apikey` 语义：access_key + secret_key、状态启停、按用户隔离、数量上限约束）。
- 对外 API 支持 API-Key 鉴权作为 Sa-Token 之外的接入凭证形式（Sa-Token token 与 API-Key 双通道可配置）；密钥加密存储（沿用敏感配置加密约束），私钥/密钥不回显，日志不输出完整密钥。
- MCP 通道鉴权走框架 SaTokenOAuth2 体系；API-Key 主要供 REST/SSE 业务对接使用。

## 6. Excel 导入（D17/D39）

- 导入 Excel 数据到问数实例绑定的数据源：自动建表写数据（需业务库允许建表），导入即可问数。
- 导入完成后自动生成表结构登记并触发向量化（D39），导入的表立即进入表匹配可问数。
- 术语库/训练示例支持按模板 Excel 导入导出；数据源 schema 支持导入导出（表结构登记与本地注释迁移，D43）。

## 7. API 对接与 UI 对接（D20/D21）

- **API 对接**：业务方用自己的 UI 调用问数 REST/SSE API（含流式），依据公开接口契约完成对话问数，不依赖框架用户端 UI。契约文档冻结接口路径、字段、SSE 事件格式、错误码。
- **UI 对接**：业务系统以嵌入/弹窗方式集成框架用户端对话 UI，对话功能在嵌入环境中可用；嵌入方式（iframe/组件挂载）、认证态透传（Sa-Token token 注入）方式给出规范。
- D21：业务客户端如何对接、如何集成 token、如何组织界面均由业务自行安排，框架不做约定。

## 8. 嵌入集成（企微/钉钉/飞书，D11）

- 首版提供向企微/钉钉/飞书三类平台嵌入的集成规范与最小支持：以「H5 页面内嵌用户端对话 UI」+ 平台入口配置为形态，登录态经平台 OAuth/扫码与 Sa-Token 打通；平台侧的机器人/事件回调通道列为对接指南级支持，功能实现以业务按规范落地为主。
- 嵌入集成的问数调用仍走同一对外 API 与同一问数核心，不新增独立编排路径。

## 9. 约束与非目标

- 不复制 SQLBot 代码（类 GPLv3 许可），仅对齐功能设计；不提供 SQLBot 平台账号类接口。
- 对外 API 不依赖 magicapi 引擎：API 服务为独立模块，模型/连接池/SQL 执行均自建（D23/D24/D27）。
- 全部对外能力（问数对话/会话历史/图表数据）在 REST/SSE 与 MCP 两条通道语义一致；管理端能力不经 MCP 暴露。
- Java 1.8 语法基线（禁 `List.of()` 等 Java 9+ API），包名 `com.xiongx9527.fw.plus.*`，版本基线与 magicapi 自维护 2.2.2 约束遵循 AGENTS.md。
