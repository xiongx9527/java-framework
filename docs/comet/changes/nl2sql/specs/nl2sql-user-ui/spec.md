# nl2sql-user-ui 用户端 UI 完整目标规格

> **文档角色**：本文档为 Comet Native change `nl2sql` 的 capability `nl2sql-user-ui` 的完整目标规格（Shape 产物），承接 brief 中的「用户端 UI（nl2sql-user-ui）」验收小节与相关决策（D7/D14/D15/D20/D30）。只描述行为与契约，不含代码实现。

用户端为**独立**问数对话 UI（独立 Vue3 应用，不嵌 magic 控制台、不嵌第三方控制台），通过 SSE 流式对接问数 API 服务（`nl2sql-core` 提供的对外 REST/SSE 对话 API，复用 SimpleAssistant 通道，D30）。管理端各页均在 magic 插件内（另一 capability，不在本文范围）。

## 1. 用户端范围

- 形态：独立 Vue3 + Vite 单页应用，构建产物为静态资源（随 API 服务或业务静态资源托管发布），不进入 magic 控制台，也不与其共享壳。
- 功能范围：会话列表与管理、流式对话、结果呈现（数据列表 + 图表）、SQL 预览/调整入口、结果反馈（点赞/点踩）、导出入口。
- 不做：用户/角色/工作区管理（沿用既有非目标）；平台模型/系统参数配置页面；管理端的表结构/术语/训练/提示词/权限策略页（均在 magic 插件）。
- 消费的后端能力：对外 REST/SSE 对话 API（会话列表/消息历史/问数对话/结果数据/图表配置/导出/推荐问题），复用同一问数核心与共享配置（D30）。
- 多实例：页面可切换/选择问数实例（每个实例绑定自己的数据源/向量库/LLM/权限策略，D8/D30），切换后会话列表与问数行为随实例切换。

## 2. 会话列表

- 左侧会话栏展示当前实例下、当前用户的历史会话：标题、最近更新时间、可选的预览。
- 会话标题默认取首个问题摘要，可**重命名**（用户编辑后持久化）；支持**删除**（逻辑删除/确认后生效，对应记录库中的会话删除）。
- 点击会话可**历史回看**：按记录库中的消息历史完整还原（用户问题、生成 SQL 展示态、结果数据快照分页、图表配置、解读文本、耗时等），回看为只读；历史结果数据通过后端服务分页接口（page/size 返回当前页与总行数）翻页，不一次性拉取全量（记录库仅存受行数限制上限约束的快照，默认 ≤1000 行，不变量）。
- 新建会话即创建空会话，首条消息发送时落库；多轮对话在同一会话内延续上下文（记录库持久化，服务重启后可回看）。

## 3. 流式对话

- 用户输入问题 → 前端 POST 对话接口建立 SSE 连接 → 逐步渲染过程事件与最终结果：
  - 过程事件：意图分支（查数/闲聊）、表匹配结果、生成中的 SQL 片段、ReAct 自愈轮次的工具调用轨迹摘要（get_table_schema / execute_readonly_sql / validate_sql）、错误提示与 regenerate 重试提示。
  - 最终结果：自然语言解读、图表配置（类型/轴）、数据结果（后端分页拉取）、导出入口、反馈入口。
- SSE 断开/网络错误时给出明确提示，支持重试；重试保留当前会话上下文。
- 确认模式实例：SSE 中推送待确认 SQL 卡片，用户可编辑后确认执行或取消；自动执行模式直接执行并回显 SQL。SQL 人工调整（D44）：对已生成 SQL（含自动执行模式）可手动修改后重新执行，仍过只读校验与数据权限回调，成功后保存为新记录。
- 闲聊兜底开启的实例，闲聊问题以通用对话 agent 流式回复（不查库、不生成 SQL）；关闭时返回无法回答数据问题的提示。
- 用户端**默认不展示原始 SQL 明文**（D19，可配置开启）；展示的 SQL 内容在传输与日志层按脱敏形态处理。

## 4. 图表切换

- 结果区根据后端返回的图表配置自动渲染默认图表（柱/条/线/饼/表之一，类型与轴由配置决定）。
- 用户可在表格/柱状图/条形图/折线图/饼图之间**切换**：前端按同一结果数据与语义（维度/指标/轴映射）重新渲染，切换不重新请求问数核心。
- 渲染思路对齐 SQLBot：表格用 `@antv/s2`（TableSheet），图表用 G2 系列；图表配置来自 LLM 产出，前端不重新推断图表类型（切换仅在渲染层生效）。
- 数据列表与图表并存：图表为整体概览，数据列表为后端服务分页逐页浏览；两者均基于同一结果集快照。
- 服务端出图（PNG）供导出/非流式场景使用（D42），前端在导出图表图片时调服务端渲染接口。

## 5. 嵌入/弹窗对接（D20）

- UI 对接形态：业务系统以**嵌入**（iframe 或组件挂载）或**弹窗**方式集成本用户端对话 UI。
- 集成约定：业务系统传入问数实例标识与 Sa-Token 登录态凭证（token），页面据此完成鉴权与对话功能；嵌入环境（企微/钉钉/飞书 WebView 或业务系统 iframe）中对话、会话管理、图表展示、流式接收均可用。
- 页面不自造登录流程；未登录/凭证失效时提示业务侧引导登录或刷新凭证。
- 路由/挂载点与业务系统解耦：以独立入口路由提供（如 `/nl2sql/` 前缀），支持按业务需要隐藏/显示实例切换等区域。

## 6. 认证对接 Sa-Token（D14）

- 页面所有对外 API 请求携带 Sa-Token token（请求头传递）；401/未登录态统一跳转或提示。
- 登录态与权限上下文（用户/部门/角色）由问数 API 服务（Sa-Token 授权服务端，D18）解析，直接供数据权限回调透传业务（D2/D14）；用户端不实现任何认证/授权判定逻辑。
- MCP 通道走既有 SaTokenOAuth2 认证体系（D18/D40），与用户端无关，仅说明交付通道一致性。

## 7. 约束与非目标

- Java 1.8 语法约束（后端 API 侧），前端技术栈为 Vue3 + Vite，与 magic 控制台插件前端一致风格但独立构建。
- 用户端不调用 magicapi 引擎，仅消费问数对外 API；不在页面内实现 SQL 生成/执行。
- 不做用户管理/角色体系定义（D11 非目标延续）；不替业务决定业务对接形态（D21）。
- 构建产物校验、流式对话联调为 Build 验收项；多方言真库效果以 MySQL 验收（D16）为基准，UI 行为不区分方言。
- 不重复 brief 全文场景描述；本节作为 user-ui capability 的行为基线，实现 change 的验收以本节小节为准。
