# 存储能力矩阵

默认内存实现用于单机开发和临时运行。开启 `state.cluster-mode=true` 时，默认 `memory` 状态会在启动期被拒绝，避免节点本地状态被误用于集群。JDBC、Redis 和业务自定义共享实现是 SPI 接入方向，不是当前 Starter 自动提供的生产适配器。

| 数据类别 | 默认实现 | 集群要求 | JDBC/Redis/业务自定义方向 | 容量与治理 |
| --- | --- | --- | --- | --- |
| 会话/消息 | Core 内存会话存储 | 必须共享、可恢复 | JDBC 适合历史和检索；Redis 适合热点与短会话；业务实现需分区 | 按项目、操作人、会话分区；设置消息 TTL 与归档。 |
| 检查点/恢复令牌 | 内存，单会话默认最多 100 个 | 必须共享并具版本、租约和幂等 | JDBC 保留版本历史；Redis 存活跃恢复状态；业务实现维护迁移 | 仅完成可重入节点可恢复；SQL 不确定时不重放。 |
| Agent 状态 | 内存 | 共享状态、租约和抢占控制 | Redis 适合短时状态/租约；JDBC 适合审计化状态 | 以请求和节点分区，设置心跳、过期和幂等键。 |
| 长期记忆 | 内存 | 不得跨节点丢失 | 内置共享适配支持 `jdbc`/`redis` client 的 `remember/find/forget` 与遗忘审计；也可提供业务 `AskDataLongTermMemory`，向量存储用于语义召回 | 以项目和操作人双重隔离，设置过期、撤销与删除策略；Starter 不创建 client、schema、keyspace 或凭据。 |
| 推荐画像 | 内存 | 必须共享且不跨人 | JDBC 适合偏好/反馈；Redis 适合缓存排序；业务实现可接算法平台 | 以项目、操作人、数据源和语义版本分区。 |
| 向量检索 | 内存向量，默认 `top-k=5` | 禁止使用本地内存 | 业务向量服务或 JDBC/向量扩展需注册 SPI | 估算向量维度、文档量、索引副本、召回延迟与重建窗口。 |
| SQL 审计 | 插件链内存审计记录 | 应持久化并可查询 | JDBC 审计表、消息投递或企业审计服务 | 记录最小必要字段，SQL/参数/结果须脱敏且有保留期。 |
| 监控日志 | 每项目+操作人范围最多 1000 条内存日志 | 必须共享、脱敏、可授权查询 | JDBC、消息系统或业务日志平台 | 生命周期日志强制写入；外部导出失败不影响本地日志。 |
| 模型路由诊断 | 最多 100 条内存快照 | 需要集中监控而非本地快照 | 业务观测 SPI 或日志平台 | 只记录逻辑 key、路由层级、稳定错误码和重试标识。 |

## 共享存储契约

共享实现必须保持 `projectId + operatorId` 隔离，并在会话、恢复、Agent、记忆、推荐和监控查询中传递同一上下文。集群节点要使用租约、乐观版本或等价并发控制；恢复时比对检查点版本、权限、语义版本、SQL 校验状态和幂等键。

## 容量规划

先按活跃项目数、操作人数、每会话消息数、并发请求、Agent 节点数、每请求日志数、向量维度和保留期估算容量。热点会话、检查点和 Agent 状态可用 Redis 类共享缓存，但需将可审计的历史同步至持久化存储。向量库扩容须验证副本、索引重建、跨节点一致性和召回延迟。

## 迁移与故障处理

从内存迁移到共享存储前应停止或排空活跃请求，建立新存储、执行契约测试、灰度写入和可读性核验。不要把内存状态视为可完整迁移的事实来源。共享存储故障时，拒绝需要状态一致性的恢复或异步继续执行；不能通过退回任一节点的本地内存来伪造集群一致性。

## 迁移检查表

1. 为目标存储建立独立命名空间，按 `projectId + operatorId` 建立索引和访问策略。
2. 排空新请求，等待运行中的 SQL、工具调用和外部副作用进入确定状态；不复制执行中的不确定节点。
3. 以只读方式校验会话、检查点、Agent 状态、记忆、推荐、审计和监控日志的数量、版本、租约和脱敏字段。
4. 开启双写或灰度写入，比较新旧存储的版本和幂等键；发现差异时暂停切换，不删除旧数据。
5. 切换读取后观察恢复、并发租约、过期清理和跨节点查询，再保留旧存储只读窗口。
6. 完成回滚演练后再清理旧数据；清理前导出审计摘要和删除证明。

## 脱敏验证

日志和共享存储中只能保存逻辑模型 key、稳定错误码、项目/操作人摘要和请求关联 ID。以下值必须被掩码或哈希：模型密钥、数据库 URL、用户名密码、连接属性、完整 token、企业平台 secret、AES-Key、原始模型响应、SQL 参数值和敏感查询结果。验证使用字段级断言和原文扫描，断言内容不得把真实凭据写入测试输出。
