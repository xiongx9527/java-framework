# TinyEngine 登录与注册页 Enter 提交设计

## 目标

TinyEngine 登录页中，当用户名或密码输入框获得焦点时，用户按 Enter 可以触发登录。注册页中，当用户名、密码或确认密码输入框获得焦点时，用户按 Enter 可以触发注册。两个页面都仅在现有可提交条件满足时发起请求。

## 现状

登录组件位于 `Login.vue`，注册组件位于 `Register.vue`。两个页面的按钮分别通过 `click` 调用 `handleLogin` 和 `handleRegister`，目前都没有键盘提交入口。

## 设计

在两个页面各自的 `TinyForm` 上监听 `keyup.enter`，利用键盘事件冒泡覆盖表单内的输入框。Enter 事件与对应按钮共用现有处理函数，不新增请求路径。

`handleLogin` 在发送请求前检查 `isReady`。用户名或密码为空时直接返回，不调用登录接口；两项均有值时维持现有请求、token 保存、用户信息加载和错误处理流程。

`handleRegister` 在发送请求前检查 `isReady`。用户名、密码或确认密码为空，密码不符合规则，或两次密码不一致时直接返回，不调用注册接口；条件满足时维持现有注册成功流程。

不改变忘记密码、后端接口、登录成功或注册成功后的页面行为。

## 验证

使用真实浏览器先验证旧页面按 Enter 不会提交，观察预期失败；实现并构建后使用相同步骤验证登录与注册 Enter 提交成功。现有前端资源测试继续作为构建回归验证。

重新构建 TinyEngine 控制台资源、安装 Starter 并重启示例服务。最终在登录页分别验证：

- 用户名和密码均有值时，在任一输入框按 Enter 只触发正常登录流程。
- 任一字段为空时按 Enter 不发起登录请求。
- 点击登录按钮仍可正常登录。
- 注册信息满足现有校验时，在任一注册输入框按 Enter 只触发正常注册流程。
- 注册信息不完整、密码不合规或两次密码不一致时按 Enter 不发起注册请求。
- 点击注册按钮仍可正常注册。
