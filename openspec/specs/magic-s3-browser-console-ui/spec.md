# magic-s3-browser-console-ui Specification

## Purpose
规范 S3 文件管理插件页面在 Magic 控制台中的布局、交互状态和错误提示行为，确保该页面保持插件 UI 边界、保留既有文件浏览操作，并在关键失败场景中通过弹窗向管理员展示可读错误。
## Requirements
### Requirement: S3 文件管理页面遵循 Magic 控制台风格
S3 文件管理页面 SHALL 使用与原 magic-s3 数据源配置页面一致的控制台布局、控件、间距、边框和主题变量。页面 SHALL 避免独立应用式卡片、营销式布局或与宿主控制台不一致的视觉风格。

#### Scenario: 页面打开后呈现控制台风格
- **WHEN** 管理员通过 S3 插件工具栏打开文件管理页面
- **THEN** 页面顶部操作区、表单控件、列表区域和详情区域使用 Magic 控制台一致的紧凑布局与主题变量

#### Scenario: 保持插件 UI 边界
- **WHEN** S3 文件管理页面被实现或构建
- **THEN** 页面源码和入口保持在 `fw-plus-magicapi-plugin-s3/src/console` 插件 UI 内，不迁移到宿主 UI

#### Scenario: 插件工具栏追加到现有工具栏后面
- **WHEN** Magic 控制台加载 S3 插件工具栏
- **THEN** 插件工具栏追加到现有工具栏之后，不插入到工具栏列表前面

#### Scenario: 控制台前端资源使用同一次构建产物
- **WHEN** Magic 控制台前端资源被 Maven 打包
- **THEN** `magic-editor/index.html` 与其引用的 `assets` 文件来自同一次前端构建，避免 hash 资源引用后出现 404

### Requirement: S3 文件管理功能保持可用
S3 文件管理页面 SHALL 保留现有文件浏览能力，包括选择存储、路径导航、搜索、加载更多、basePath 保存、预览、下载和删除。视觉调整 MUST NOT 移除或破坏这些已有功能。

#### Scenario: 管理员浏览对象列表
- **WHEN** 管理员选择一个可用 S3 存储并进入路径
- **THEN** 页面展示该路径下的对象和目录，并允许继续切换路径或加载更多

#### Scenario: 存储下拉默认显示请选择
- **WHEN** 页面加载可用 S3 存储列表
- **THEN** 存储下拉默认保持空选项并显示“请选择”，不自动选择第一个存储

#### Scenario: 基础路径默认只读并按需编辑
- **WHEN** 管理员未点击基础路径编辑按钮
- **THEN** 基础路径输入框不可编辑，按钮显示“编辑”
- **WHEN** 管理员点击编辑按钮
- **THEN** 基础路径输入框进入可编辑状态，按钮显示“保存”

#### Scenario: 管理员执行文件操作
- **WHEN** 管理员选择文件并点击预览、下载或删除操作
- **THEN** 页面调用对应 S3 浏览接口并保持原有操作语义

#### Scenario: 未选中文件时隐藏详情框
- **WHEN** 管理员未选中任何文件或切换路径后清空选择
- **THEN** 页面不展示文件详情框，也不展示默认的详情占位提示

#### Scenario: 选中文件后展示详情框
- **WHEN** 管理员选择一个文件
- **THEN** 页面展示文件详情框，并提供预览、下载和删除操作

### Requirement: 操作错误通过弹窗或消息提示
S3 文件管理页面 SHALL 在加载存储、列文件、预览、下载、删除和保存 basePath 失败时，通过 Magic 控制台可见的弹窗或消息机制提示错误。错误提示 MUST 包含后端返回的错误信息或可读的失败原因。页面正文 MUST NOT 渲染错误提示条、错误占位或错误文本。

#### Scenario: 列文件失败时弹出错误
- **WHEN** 管理员选择的 S3 存储未注册、配置错误或接口返回失败
- **THEN** 页面弹出错误提示并显示后端返回的失败原因，且页面正文不展示错误文本

#### Scenario: 删除失败时弹出错误
- **WHEN** 管理员删除文件失败
- **THEN** 页面弹出错误提示，并且不把失败误显示为删除成功

#### Scenario: 预览或下载失败时弹出错误
- **WHEN** 管理员预览或下载文件失败
- **THEN** 页面弹出错误提示，并保留当前文件列表和选择状态
