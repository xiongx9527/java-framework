### 切分方法（避免 hunk 级手术）
按「文件粒度」分组，不碰 `git add -p`：

1. `git status --porcelain` 全量导出到 `/tmp/all_changed.txt`，去掉状态码列。
2. 用路径前缀 grep 分出 6 组，**先用计数核对各组之和 == 总路径数**（确认互斥且无遗漏）：
   - G1 工具链 3（`.gitignore` / `AGENTS.md` / `CLAUDE.md`）
   - G2 langchain4j 其余 75（51 个 R100 重命名 + 删 `fw-plus-ai-langchain4j-parent` + 该层 22 个 pom）
   - G3 agentic 30
   - G4 tinyflow 15
   - G5 其余 pom 147
   - G6 docs 17
   - 残余 2：`.claude/` `.workbuddy/`（故意不提交）
3. **重命名行的坑**：`git status --porcelain` 里重命名是 `R100\told -> new` 一行两路径，直接拿去 `git add` 会失败。用 `awk '{gsub(/ -> /,"\n"); print}'` 拆成两行后再 stage（旧路径不存在也能被 `git add -A --` 正确记为删除，commit 时 git 自动识别为 R100）。
4. 逐组 `git add -A -- $(cat /tmp/cmt/gN.txt)` + `git commit -m 标题 -m 正文`，每组提交前打印 `git log --oneline -1` 确认。
